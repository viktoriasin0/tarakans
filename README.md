# tarakans
Руководство по игре «Тараканьи бега»
Описание игры
Компьютерная игра-симулятор гонок двух виртуальных тараканов. Игроки соревнуются в скорости прохождения дистанции.

Интерфейс игры
Заголовок окна: «тараканьи бега»
Текстовые поля для ввода имен игроков
Счетчики прогресса (отображаются в label1 и label2)
Информационная панель (label3) для вывода результатов
Изображения тараканов на беговой дорожке
Кнопки управления: «СТАРТ» и «сброс»
Элементы управления
Кнопка «СТАРТ»: запускает гонку после ввода имен игроков
Кнопка «сброс»: возвращает игру в исходное состояние
Текстовые поля: для ввода имен участников
Правила игры
Введите имена двух игроков в текстовые поля
Нажмите кнопку «СТАРТ» для начала гонки
Наблюдайте за движением тараканов по дорожке
Следите за счетчиками пройденного пути
Дождитесь финиша одного из участников
Механика игры
Движение тараканов происходит случайным образом
Скорость перемещения определяется генератором случайных чисел
Каждый таракан может пройти от 0 до 8 единиц за один шаг
Побеждает тот, кто первым достигнет финиша
Особенности работы
Таймер обеспечивает периодичность движения (интервал 50 мс)
Счетчики отображают точное расстояние, пройденное каждым тараканом
При достижении финиша игра автоматически останавливается
В случае победы выводится имя победившего игрока
